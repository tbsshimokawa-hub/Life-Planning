# ライフプランニングシステム
### Money Advice Center — FP・IFA向け顧客提案ツール

ブラウザ上で完結する、FP・IFA向けのライフプランニング表作成ツールです。
サーバー不要・インストール不要。HTMLファイルを開くだけで即座に使用できます。

## 機能概要

### 📊 ライフプランニングシステム（index.html）

ヒアリング情報を入力するだけで、将来のキャッシュフロー表とグラフを自動生成します。

**6ステップ入力フロー**

| ステップ | 入力内容 |
|---|---|
| 1. 基本情報 | 本人・配偶者・お子様の年齢・氏名 |
| 2. 収入 | 給与・退職金・その他収入（再雇用、個人年金、不動産収入 など） |
| 3. 支出 | 生活費・家賃・保険料・その他支出（車両費、習い事 など） |
| 4. 資産・負債 | 預貯金・投資資産（受取用／増加用）・住宅ローン |
| 5. ライフイベント | 住宅購入・車購入・旅行・リフォーム・結婚 など |
| 6. プラン表 | キャッシュフロー表＋資産推移グラフの表示・PDF出力 |

**シミュレーション設定（プラン表画面・サイドバー）**

- 年収上昇率 / 物価上昇率
- 預貯金運用利回り
- 投資資産（受取用）の年率複利・毎年の受取額
- 投資資産（増加用）の年率複利
- 退職年齢 / 年金月額 / 年金開始年齢
- 住居費増減率 / 教育プラン（公立中心・私立中心）

**PDF出力**
プラン表・グラフをPDFとして保存し、顧客への説明資料として活用できます。

---

### 📈 リスク・リターン シミュレーター（simulation.html）

投資の将来シナリオを確率論的に可視化するツールです。
対数正規分布＋平均回帰（Ornstein-Uhlenbeck）モデルを採用しています。

**調整パラメーター**

| パラメーター | 説明 |
|---|---|
| 期待リターン（算術平均） | GPIFなどの公表値をそのまま入力可能 |
| リスク（標準偏差） | 年率標準偏差（例：外国株式 ≈ 20%） |
| 初期投資金額 | 単位：万円 |
| シミュレーション期間 | 1〜50年 |
| 平均回帰強度 κ | 0＝従来モデル、大きいほど平均回帰が強い |

**グラフ表示内容**

| ライン | 意味 |
|---|---|
| 中央値（期待値） | 50%の確率でこのラインを超える |
| ±1σ | 上位15.9% / 下位15.9% のシナリオ |
| ±2σ | 上位2.3% / 下位2.3% のシナリオ |

**幾何平均（ボラティリティドラッグ）の自動表示**

GPIFなどが公表する「期待リターン」は**算術平均**です。
実際にグラフの中央値（半数の投資家が達成できる年複利）は**幾何平均**であり、以下の式で算出されます。

```
幾何平均（中央値の年複利） ＝ 算術平均リターン − σ² / 2
```

> 例）外国株式：算術平均 7.6%、σ 20%
> → 幾何平均 = 7.6% − 2.0% = **5.6%**

パラメーターが変わるたびに幾何平均をリアルタイム表示するため、GPIFの数値を引用した顧客説明でも数字のズレが生じません。

## 使い方

1. `index.html` をブラウザで開く
2. ステップに沿って顧客情報を入力する
3. 「ライフプラン表を作成」ボタンでキャッシュフロー表・グラフを確認
4. 必要に応じてPDF出力、または `simulation.html` でリスク・リターンの補足説明を行う

> **注意：** グラフ描画ライブラリ（Chart.js）をCDNで読み込むため、初回表示時にインターネット接続が必要です。
> それ以外のサーバー・インストールは一切不要です。

## 数理モデル（シミュレーター）

```
資産価値 P(t) は対数正規分布に従う

中央値（幾何平均パス）：
  P0 × exp((μ − σ²/2) × t)

有効累積ボラティリティ σ_eff(t)：
  κ = 0 のとき → σ_eff = σ√t（標準ランダムウォーク）
  κ > 0 のとき → σ_eff = σ × sqrt((1 − exp(−2κt)) / (2κ))
                  ※長期でσ/√(2κ)に収束（Ornstein-Uhlenbeck型平均回帰）

±nσ ライン：
  P0 × exp((μ − σ²/2) × t ± n × σ_eff(t))
```
